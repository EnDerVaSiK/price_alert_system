# 🛒 Price Alert System

Микросервисная система для автоматического отслеживания снижения и изменения цен на товары в интернет-магазинах. Проект построен на современных асинхронных технологиях Python (FastAPI, asyncio) и React.

## 🏗 Архитектура системы

Система представляет собой микросервисный комплекс, построенный на базе асинхронного взаимодействия. Компоненты общаются между собой через Redis Pub/Sub и очереди задач, что обеспечивает высокую масштабируемость.

1. **API Gateway (Telegram Bot)**: Точка входа. Реализован на aiogram, обрабатывает команды пользователя и управляет подписками в PostgreSQL.
2. **Scheduler**: Планировщик, который раз в минуту опрашивает базу данных и формирует список тикеров для парсинга.
3. **Parser**: Опрашивает MOEX ISS API, получает актуальные котировки и передает их в анализатор.
4. **Analyzer**: Сравнивает текущие цены с сохраненными в БД, отслеживает изменение цен (рост/падение) и формирует алерты.
5. **Notifier**: Финальный сервис, который получает отформатированный алерт и отправляет его пользователю через Telegram Bot API.

## 🚀 Быстрый запуск

Для локального запуска убедитесь, что у вас установлены Docker и Docker Compose.

### 1. Подготовка окружения

Настройка окружения:
Создайте файл .env в корне проекта на основе .env.example (укажите ваш TELEGRAM_BOT_TOKEN и параметры БД).

### 2. Запуск всех сервисов:

```bash
docker-compose up --build
```

Система автоматически создаст таблицы в PostgreSQL, запустит всех воркеров и Telegram-бота.

### 3. Запуск автотестов (опционально):

```bash
# Для запуска с удалением контейнеров БД после теста:
docker-compose run --rm api-gateway bash -c "pytest tests/ -v" ; docker-compose down
```

## Взаимодействие

Поскольку система работает как Telegram-бот, взаимодействие пользователя с API происходит через команды:

| Команда | Описание |
| - | - |
| /start | Регистрация пользователя в БД и открытие меню управления. |
| 📈 Выбрать акции | Вывод Inline-клавиатуры для подписки на популярные тикеры (SBER, GAZP и др.). |
| 📋 Мои подписки | Просмотр текущих тикеров и цен, установленных при подписке. |
| 🗑 Отписаться от всего | Полное удаление всех подписок пользователя. |

## Примеры внутренних событий
Взаимодействие между сервисами происходит путем публикации JSON-сообщений в очереди Redis:

* Вход в очередь парсинга (queue:parse):

```json
{"tickers": ["SBER", "GAZP"]}
```

* Алерт об изменении цены (queue:notify):

```json
{
  "telegram_id": 123456,
  "text": "🔴 Упала!\n\nАкция: <b>SBER</b>\nСтарая цена: <s>325.74 ₽</s>\nНовая цена: <b>300.0 ₽</b>"
}
```

## Стек технологий

* Python 3.11+
* AIOGRAM 3.x (Telegram bot interface)
* SQLAlchemy + asyncpg (ORM и работа с PostgreSQL)
* Redis (Очереди задач и кэширование)
* Httpx (Асинхронные HTTP-запросы к бирже)
